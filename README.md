## ⚙️ Getting Started

Each project is independent, so run them one at a time.

```bash
# 1. Clone the repository
git clone https://github.com/Habibullah-R/DEP.git
cd DEP

# 2. Move into the project you want to run
cd "ecommerce"        # or "portfolio", "Blog app with messaging", "Blog App task # 2"

# 3. Install dependencies
npm install

# 4. Start the project
npm start             # or: npm run dev
```

> **Note:** Projects with a backend may need a `.env` file (for example a database connection string). Check the project folder for required variables before starting.
